# Changelog

`pulse_slab_generator` is an internal repository tool (`publish_to: none`),
not a separately released pub.dev package. Its version tracks compatibility
with this repository's source and supported `pulse_slab` APIs.

## 0.3.0-beta.1

- Added optional annotation-driven generation of Pulse Slab layouts, typed
  access helpers, serializers, deserializers, and validation hooks, consumed
  through a Git or local path development dependency.
